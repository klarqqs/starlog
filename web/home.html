API metrics

The half a website tracker cannot do

Create an ingest token per project and send request metrics. Starlog strips Stellar addresses, UUIDs, hashes and ids from paths, then keeps request counts, status codes and p50/p95 latency.

How it works

From sign-up to numbers in four steps

1. Register

Create a project with your email and verify it.

2. Add a domain

Tell Starlog which site or API is yours.

3. Paste the snippet

One script tag for the website, or an ingest token for your API.

4. Read your dashboard

Only your numbers. Share a totals-only link if you want.

Privacy

No cookies. No personal data.

Visitors are counted with a daily-rotating hash and a truncated IP. Raw IPs and cookies are never stored. Rollups are kept per project and isolated by Postgres row-level security.

No consent banner

Nothing is stored on the visitor’s device beyond a per-tab session flag.

Strict isolation

Every query runs under one project’s identity.

Your data stays yours

Self-host from one repository, or use the shared service.

Built in the open
