Privacy

What Stellog collects

Web analytics

  • Page views, referrer host, browser, and device type, added to daily totals.
  • A unique-visitor count made from a hash of site, day, truncated IP and user agent. The hash changes every day, so visitors cannot be followed across days.
  • No cookies. The tracker keeps one flag in session storage to count a new session.
  • Events are accepted only from the domain a project registered.

API metrics

  • Request counts, status codes and latency histograms per normalized route.
  • Stellar addresses, UUIDs, hashes and numeric ids are removed from paths before storage.
  • No request bodies, headers, traces or logs are stored.

Accounts

  • Project email address and an argon2id password hash. Sessions are stored hashed.

Still to come

A full GDPR write-up, data-residency statement and erasure workflow are planned in the milestone plan and are not yet published.
