Get counted in five minutes

Quick start

  1. Register your project and verify your email.
  2. Add a website or API domain in the dashboard.
  3. Install the snippet or send metrics (below).

Install the web tracker

Paste this in the <head> of your site. Use the site id shown in your dashboard.

<script defer src="https://YOUR-STARLOG-HOST/s.js"
        data-site="SITE-ID"></script>

Visits count only when the browser origin matches the domain you registered. Use Send a test visit in the dashboard to check it works.

Send API metrics

Create an ingest token in the dashboard, then post batches of up to 50 points from your server. The token identifies your project.

curl -X POST https://YOUR-STARLOG-HOST/v1/metrics \
  -H "Authorization: Bearer sl_YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domain":"api.example.com","points":[
        {"path":"/accounts/GABC.../payments?limit=5","status":200,"latencyMs":42}]}'

The domain must be an API site you added. Paths are normalized before storage, so the example above is stored as /accounts/:id/payments. Responses: 200 with the accepted count, 401 for a missing or unknown token, 404 if no API site matches the domain.

Share

Turn on the share link in the dashboard to publish totals only at /share/your-slug. Turn it off to revoke it.

Sign in, password reset and wallets

Projects sign in with email and password at /login. If you forget the password, use Forgot your password?: we email a link that is valid for 1 hour and works once, and a reset signs you out everywhere.

After you sign in you can link Freighter or xBull in the dashboard (up to 5 wallets). Linking asks the wallet to sign a short challenge for this site. Nothing is sent to the Stellar network and no funds move. After that, the wallet buttons on the sign-in page sign you in without the password. A wallet belongs to one account.

SCF operators

Operators sign in at /operator/login, a separate door from the project one. A project account cannot use it. The first operator is created by whoever runs the service: make operator EMAIL=… PASSWORD=…. After that, any operator can invite colleagues from the operator page: they get an email, choose their own password, and can be removed again. The last active operator cannot be removed.

Self-host

git clone https://github.com/klarqqs/starlog
cd starlog && cp .env.example .env   # set every CHANGE-ME
make up
make operator EMAIL=you@example.org PASSWORD='12+ characters'

The app is then on http://127.0.0.1:4000. In development, verification and reset links print in make logs. For wallet sign-in run make wallet-key and paste the line into .env.
