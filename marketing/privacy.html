Privacy

What Stellog collects

Web analytics

The tracker is Umami’s. It does not use cookies. Page views and the reports in the dashboard are stored for the website you added.

Accounts

  • Username and a bcrypt password hash. A password reset link is stored as a hash, lasts 1 hour, and works once.
  • If you link a wallet, we store its public address only. Signing in with a wallet never sends a transaction and never touches funds.
