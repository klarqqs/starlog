Get counted in five minutes

Quick start

  1. Create an account.
  2. Add a website in the dashboard.
  3. Paste the snippet the dashboard shows.

Install the tracker

Each website has a script tag in its settings. Paste that tag in the <head> of the site. The tracker is Umami’s and does not use cookies.

Sign in, password reset and wallets

Sign in at /login. Forgot the password? Request a reset link. It lasts 1 hour, works once, and signs that account out everywhere. In development the link is printed by the server.

After you sign in, open Settings → Wallets and link Freighter or xBull (up to 5). Linking asks the wallet to sign a short challenge. Nothing is sent to the Stellar network. The wallet buttons on the sign-in page then work. A wallet belongs to one account.

SCF operators

Operators sign in at /operator/login. The button says “Sign in as operator.” The username is not an email. Project accounts use project sign in and are turned away from the operator door. A signed-in operator opens the read-only view of every project.

Self-host

git clone https://github.com/klarqqs/stellog
cd stellog && cp .env.example .env
pnpm install
pnpm dev

The app is on http://127.0.0.1:3000. Set DATABASE_URL and APP_SECRET in .env. For wallet sign-in, set STELLAR_AUTH_SECRET to a Stellar secret key. Without it, development uses a temporary key.
